### G2 — animation_fps + freetype tuning (wezterm.lua)
**Why:** `animation_fps = 60` causes GPU to wake every frame even when idle typing.
Setting to `1` lets GPU sleep between keystrokes. `freetype_load_target = "Normal"`
matches Windows ClearType hinting better than "Light" for LCD displays.

- [ ] `config.animation_fps = 1` (was 60 — GPU idles between keystrokes)
- [ ] `config.freetype_load_target = "Normal"` (was "Light" — better ClearType match)
- [ ] Keep `config.freetype_render_target = "HorizontalLcd"` (correct for LCD)
- [ ] Files: `wezterm.lua`

### G3 — Deep clean: cargo registry + go cache + docker (bootstrap.ps1)
**Why:** `cargo registry/src` and `cargo registry/cache` can be GBs. Safe to delete
— cargo re-downloads on next build. Go module cache same. Docker images/builders
accumulate fast on dev machines.

**Safe-delete confirmed by research:**
- `~/.cargo/registry/src` → re-extracted from cache on build
- `~/.cargo/registry/cache` → re-downloaded from crates.io on build
- `$(go env GOCACHE)` → `go clean -cache`, 100% safe, regenerates
- `$(go env GOMODCACHE)` → `go clean -modcache`, safe, slow rebuild
- `docker system prune -f` → images/builders, safe if docker present

**NEVER delete:** `~/.cargo/bin/` (installed tools), `~/.cargo/registry/index/` (slow rebuild)

New paths to add to `Invoke-SystemClean` APP CACHES section:
- [ ] `~/.cargo/registry/cache` + `~/.cargo/registry/src` (stale threshold: age of dir)
- [ ] `$(go env GOCACHE)` via `go clean -cache` if `go` exists
- [ ] Docker prune if `docker` exists: `docker system prune -f`
- [ ] nuget: `~/.nuget/packages` old entries (threshold: 60d)
- [ ] yarn: `%LOCALAPPDATA%\Yarn\Cache`
- [ ] pnpm store: `%LOCALAPPDATA%\pnpm-store`
- [ ] Files: `wezterm-bootstrap.ps1` → `Invoke-SystemClean` APP CACHES section
- [ ] Verify: `8sync clean --dry-run` shows new entries, nothing critical deleted

### G6 — Security: multi-layer audit pipeline (bootstrap.ps1)
**Why:** Malicious npm packages (typosquatting, post-install scripts) are #1 attack
vector on dev Windows. Two-layer approach: Defender MpCmdRun (filesystem scan) +
per-ecosystem audits (semantic vulnerability detection).

**Research findings:**
- `npm audit --json` → flags HIGH/CRITICAL CVEs in installed packages
- `cargo audit` (cargo-audit crate) → RustSec advisory database
- `pip-audit --format=json` → OSV/PyPI advisory scan
- Defender ScanType 3 on `npm-cache/_npx` catches infected MCP server binaries
- Key red flags: `postinstall` scripts with network calls, obfuscated eval/atob

New `Invoke-EcosystemAudit` function:
- [ ] Find all `package.json` in HOME roots depth 3, run `npm audit --json`,
      report CRITICAL/HIGH only
- [ ] `cargo audit --json` if `cargo-audit` installed, report advisories
- [ ] `pip-audit --format=json` if installed, report HIGH severity
- [ ] Scan `node_modules/*/package.json` for `postinstall` scripts with
      network calls (curl/wget/http/fetch patterns) — red flag report
- [ ] Wire as `8sync clean --audit` command (separate from `--scan`)
- [ ] Files: `wezterm-bootstrap.ps1`, `Invoke-CleanCommand`, completer, hint
- [ ] Verify: `8sync clean --audit` shows per-ecosystem vulnerability table

## Safe-Delete Reference (DO NOT DELETE list)

| Path | Reason |
|------|--------|
| `~/.cargo/bin/` | Installed tools — only delete specific stale .exe |
| `~/.cargo/git/` | Cloned git deps — delete breaks git-sourced deps |
| `$(go env GOPATH)/bin/` | Installed go tools — same as cargo/bin |
| `%APPDATA%\npm\` (root) | npm itself — only clean `node_modules` subdir |
| `%LOCALAPPDATA%\anthropic\` | Claude Desktop state |
| `%APPDATA%\cursor\` | Cursor editor state |
| `%APPDATA%\Code\User\globalStorage\` | VS Code extensions state |
| `~/.ssh/` | SSH keys |
| `~/.config/` | User configs (including this repo) |
| Any `.git/` dir | Never delete — kills repo history |

| Path | Safe to delete | Notes |
|------|---------------|-------|
| `~/.cargo/registry/cache/` | ✅ Yes | Re-downloaded on `cargo build` |
| `~/.cargo/registry/src/` | ✅ Yes | Re-extracted from cache |
| `~/.cargo/registry/index/` | ⚠️ Careful | Slow `cargo update` to rebuild |
| `~/.cargo/git/checkouts/` | ✅ Yes | Re-checked out on build |
| `~/.cargo/git/db/` | ⚠️ Careful | Full re-clone needed |
| `~/.cargo/bin/` | ❌ NEVER | Installed tools |
| `$(go env GOCACHE)` | ✅ Yes | `go clean -cache` — regenerates |
| `$(go env GOMODCACHE)` | ✅ Yes (>30d) | `go clean -modcache` — slow rebuild |
| `npm cache` | ✅ Yes | `npm cache clean --force` |
| `pip cache` | ✅ Yes | `pip cache purge` |
| `~/.cargo/bin/*.exe` (>90d unused) | ✅ Yes | Old unused tools only |
| `node_modules/` in old projects | ✅ Yes (>90d) | `npm install` recreates |
| Docker images/builders | ✅ Yes | `docker system prune -f` |
| `%LOCALAPPDATA%\npm-cache\_npx/*` (>30d) | ✅ Yes | MCP server npx cache |
| `~/.nuget/packages` (>60d) | ✅ Yes | .NET packages, re-downloaded |
| `%LOCALAPPDATA%\Yarn\Cache` | ✅ Yes | yarn cache clean |
| `%LOCALAPPDATA%\pnpm-store` (>30d) | ✅ Yes | pnpm store prune |
