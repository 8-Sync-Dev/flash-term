# Plan: v0.3.0 — Stability, Performance, UX polish

Date: 2026-03-22
Status: in-progress

## Goals
- Warn users on unsupported PowerShell versions (P0-6)
- Shave another 100-300ms off shell startup (P1-2)
- Cleaner code structure: extract dispatch, split keybindings (P3-1, P3-4)
- Better project picker UX: show git remote origin (P2-4)

---

## Tasks

### P0-6 + P3-3 — PS version guard
- [ ] `wezterm-bootstrap.ps1` line 1: add `#Requires -Version 5.1`
- [ ] `Start-WezTermShell`: check `$PSVersionTable.PSVersion.Major -lt 5`
      → `Write-Warning` with install link, continue (do not abort shell)
- Files: `wezterm-bootstrap.ps1`
- Verify: open PS 5.0 (or spoof `$PSVersionTable`) → warning shown, shell still loads

### P1-2 — Lazy zoxide + starship init
- [ ] Move `zoxide init` and `starship init` calls out of `Set-ToolAliases`
      into a deferred `Register-ShellInits` function
- [ ] Call via `$null = [System.Threading.ThreadPool]::QueueUserWorkItem({...})`
      OR simply call after `Start-AutoSync` so they don't block prompt appearance
- [ ] `cdi` alias must still work — bind it before init completes via a stub
- Files: `wezterm-bootstrap.ps1` → `Set-ToolAliases`, `Start-WezTermShell`
- Verify: `Measure-Command { . .\wezterm-bootstrap.ps1 }` drops by ≥ 80ms

### P2-4 — --projects fzf: git remote origin column
- [ ] In `Find-StaleProjects`: add `Remote` field:
      `git -C $dir remote get-url origin 2>$null` → trim → empty string if none
- [ ] In `Invoke-ProjectPicker` fzf line format: add remote after `||` separator
      `'{0,-36} {1,7}  {2,3}d  {3,-30}  || {4}'`
      fields: Name | Size | Days | Remote(truncated 30) | Path
- [ ] `--with-nth 1,2,3,4,5` in fzf call (hide path column from display)
- Files: `wezterm-bootstrap.ps1` → `Find-StaleProjects`, `Invoke-ProjectPicker`
- Verify: `8sync clean --projects` shows origin URL column in fzf list

### P3-1 — Extract 8sync dispatch from Set-ToolAliases
- [ ] Move `function global:Invoke-8Sync { ... }` block out of `Set-ToolAliases`
      into a standalone `function Register-8SyncAlias { ... }` called at end of
      `Set-ToolAliases`
- [ ] Move `Set-Alias -Name '/8sync'` and `Set-Alias -Name '8sync'` into
      `Register-8SyncAlias`
- [ ] `Register-8SyncCompleter` call stays at end of `Register-8SyncAlias`
- Files: `wezterm-bootstrap.ps1` → `Set-ToolAliases`
- Verify: `8sync help`, `8sync sync`, `8sync clean help` all still work

### P3-4 — Split keybindings into keys.lua
- [ ] Create `keys.lua`: return table containing all key binding definitions
      ```lua
      -- keys.lua
      local wezterm = require("wezterm")
      return { ... }   -- the config.keys array
      ```
- [ ] In `wezterm.lua`: replace `config.keys = { ... }` block with:
      ```lua
      local ok, keys = pcall(dofile, config_dir .. "\\keys.lua")
      config.keys = (ok and type(keys) == "table") and keys or {}
      ```
- [ ] Both files committed together (breaking if split)
- Files: `wezterm.lua`, new `keys.lua`
- Verify: `wezterm --config-file .\wezterm.lua list-clients` no errors;
          all keybindings work (Ctrl+Shift+|, Leader+s, etc.)
